
# Excel Sales Management Dashboard

## About the Project
This project is an interactive Sales Management Dashboard developed using Microsoft Excel. It helps analyse sales performance and present business information through interactive reports and visualizations.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- VBA Macros
- Excel Charts

## Key Features
- Interactive sales dashboard
- Sales performance analysis
- Data summarization using PivotTables
- Automated tasks using VBA Macros
- Visual representation of sales data
